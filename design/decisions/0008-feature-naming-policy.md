# ADR 0008: Deterministic feature naming policy

- **Status:** Superseded by [ADR 0010](0010-explicit-feature-directory.md)
- **Date:** 2026-09-05

The reference-derived naming, `max-length`, and ownership/collision-registry
requirements are withdrawn. The supplied validated feature directory identifies
the feature. Existing derivation code is legacy implementation to remove, not
a fallback or prerequisite for the explicit-directory contract.
