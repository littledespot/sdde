# Historical fix records

These records preserve dated approval provenance, implementation history and
retained experiments. They are superseded as active work trackers by
[FIX01](../FIX01.md). Historical open/completed statuses describe their recorded
date; this archive neither closes outstanding work nor renews approvals.

| Record | Historical content |
| --- | --- |

| [FIX_002](FIX_002.md) | Source/review/clarification follow-ups, accepted amendments and the explicit D2 rollback. |
| [FIX_003](FIX_003.md) | Native phase-handoff approval, implementation evidence and unsuccessful live attempts. |
| [LLM_REWORK](LLM_REWORK.md) | Responsibility-transfer mandate, ADR 0020 approval provenance and earlier audit/delivery history. |
| [SPEC_AUTHORING](SPEC_AUTHORING.md) | Earlier authoring/guidance experiments and measurements. |
| [JSON_ISSUE](JSON_ISSUE.md) | Bedrock observations, prefix-normalization history and original [comparison evidence](evidence/). |

Remaining required work is consolidated in FIX01. Optional investigations remain
proposals requiring their applicable decisions and authorization. Accepted design
contracts and ADRs continue to govern implemented behavior.
