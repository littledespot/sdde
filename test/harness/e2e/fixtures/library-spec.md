# Feature Specification: Loan Renewal

## User Scenarios & Testing _(mandatory)_

### Primary User Story

A librarian renews a loan and sees Loan renewed!

### Acceptance Criteria

- **AC-001**: **Given** a loan, **When** the librarian renews it, **Then** the loan is renewed and Loan renewed! is displayed

### User-Visible Outcomes

- **UO-001**: Loan renewed!

## Requirements _(mandatory)_

### Functional Requirements

- **FR-001**: A librarian MUST be able to renew a loan.
- **FR-002**: Renewing a loan MUST display Loan renewed!

### Key Entities _(include if feature involves data)_

**EN-001**
- **NAME** Loan
- **BUSINESS MEANING** A library loan that can be renewed.
