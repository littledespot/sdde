# Hello World Application

## User Scenarios & Testing

### Primary User Story

The application starts successfully. Its startup greeting is `Hello, World!`, and it also provides UTC date and time output.

### Acceptance Criteria

- **AC-001**: **GIVEN** the application, **WHEN** startup is initiated, **THEN** it starts successfully and displays the exact text `Hello, World!`.
- **AC-002**: Both a date and a time are output using UTC.

## Requirements

### Functional Requirements

- **FR-001**: The application MUST output a date and a time, both expressed in UTC.
- **FR-002**: On startup, the displayed greeting MUST read `Hello, World!`.
- **FR-003**: Starting the application MUST succeed.
