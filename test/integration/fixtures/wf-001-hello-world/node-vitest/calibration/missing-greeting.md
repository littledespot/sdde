# Hello World Application

## User Scenarios & Testing

### Primary User Story

Starting the application succeeds. The application also outputs the date and time in UTC.

### Acceptance Criteria

- **AC-001**: **GIVEN** the application, **WHEN** it is started, **THEN** startup succeeds.
- **AC-002**: The application outputs both the date and the time in UTC.

## Requirements

### Functional Requirements

- **FR-001**: The application MUST start successfully.
- **FR-002**: The application MUST also output the date and time in UTC.
