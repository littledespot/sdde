# Hello World Application

## User Scenarios & Testing

### Primary User Story

The application displays `Hello, World!` and outputs the date and time in UTC.

### Acceptance Criteria

- **AC-001**: The application displays the exact text `Hello, World!`.
- **AC-002**: The application outputs both the date and the time in UTC.

## Requirements

### Functional Requirements

- **FR-001**: The application MUST display `Hello, World!`.
- **FR-002**: The application MUST output the date and time in UTC.
